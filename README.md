# MyInvest20260824

个人研究 Web 应用：首页提供自选股每日行情，市场 → 行业 → 股票研究闭环保留在 `/market`。

## V2 状态

**V2 — 个人自选股每日研究看板：完成。**

当前支持自选最新行情、当日绝对波动前五、5 日/20 日涨跌、成交额比、20 日位置、20 日迷你走势、快照时间和历史截止日，以及 A 股与 ETF 详情下钻。

当前边界：首页仅对重点前 5 个可用标的请求历史（最多 5 个）；港股当前数据源不支持；不包含新闻、AI、评分、交易信号或自动交易；`.local/watchlist.csv` 不提交 Git。

## V3 状态

**V3 — 个人研究记录闭环：进行中。**

第一步统一 A 股与 ETF 详情页的桌面优先布局；个人研究记录将优先使用浏览器本地持久化，不在当前公开服务中引入 DuckDB 或服务端笔记接口。

## 当前功能

- 自选股 A 股与 ETF 最新行情，按绝对涨跌幅排序
- 今日波动前五标的的 5 日、20 日涨跌对照
- 今日重点标的的历史成交额比（最近交易日相对此前 20 日均值）
- 今日重点标的收盘价在最近 20 个交易日区间中的位置
- 重点区区分最新行情快照与历史指标截止交易日
- 重点标的最近 20 个交易日收盘价迷你走势
- 重点标的逐行展示行情快照时间与历史指标截止日
- 不支持资产的明确状态提示
- A 股与 ETF 自选标的均可进入详情研究页
- 主要指数最新快照
- 同花顺行业最新涨跌
- 行业当前成分股与上涨宽度
- A 股最新行情快照
- 前复权日 K 与成交量
- MA20 / MA60 / MA120
- 近 60 日最大回撤
- 近 20 日平均成交额
- ETF 日线、MA 与同口径研究指标（ETF 历史接口不提供复权参数）

## 数据源

使用 Hithink Finance API 真实数据，不使用 mock 或 fallback。私人本地数据不进入公开仓库。

## 环境

复制 `.env.example` 为 `.env`，并在本地配置：

```text
HITHINK_FINANCE_API_KEY
```

不要提交 `.env` 或 API Key。

## 自选股配置

在本地创建 `.local/watchlist.csv`，格式为：

```csv
name,code,market,asset_type
山东高速,600350.SH,CN,a-share
中证500ETF南方,510500.SH,CN,fund-etf
```

`.local/` 已被 Git 忽略。该文件是运行时本地配置；当前标的会在网页公开展示。

## 本地运行

```bash
npm install
npm run dev
```

打开 <http://localhost:8030>。

市场与行业研究页：<http://localhost:8030/market>。
