# MyInvest20260824

Personal A-share research web application.

## Run

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Required environment

```text
HITHINK_FINANCE_API_KEY
```

Copy `.env.example` to `.env` and provide the key locally. Never commit `.env`.

## Data

Financial data comes from the Hithink Finance API. No mock financial data is used.
